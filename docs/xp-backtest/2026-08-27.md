## Notes

- **Model:** `basic-v1` — closed-form ridge (`alpha=1.0`), one per position group, FPL-data-only features
  (`form_points_3/5`, `form_minutes_3`, `starts_rate_5`, `form_goals_5`, `form_assists_5`, `was_home`,
  `value`, `opp_conceded_to_pos_5`). Trained on 2023-24 + 2024-25 (30,188 player-GW rows).
- **Backtest:** walk-forward over 2024-25, 30 folds, each trained strictly on prior gameweeks.
  Baseline = predict the per-position training mean.
- **Read:** all four positions beat the naive mean, by ~0.1–0.2 RMSE. That's a small but real edge —
  consistent with the known ceiling for FPL point prediction (a single deflection or red card swings
  a gameweek). The Basic tier is about *ranking* players better than the mean, not exact precision.
  Bigger gains need underlying xG/xA data and a non-linear model (Advanced tier, sub-plan P2b).
